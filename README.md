# KARAR SENİN — yayın deposu

Bu depo herkese açıktır ve sadece **yayınlanacak videoları** barındırır. Strateji ve notlar gizli depoda tutulur.

- `isler/` — Claude'un indirme işleri (her satır: `dosya_adi bağlantı`). Bir iş dosyası eklendiğinde GitHub Actions dosyaları indirir.
- `indirilen/` — HeyGen'den indirilen ham klipler ve sesler.
- `yayin/` — Kalite kontrolünden geçmiş, yayına hazır videolar. Metricool buradaki ham (raw) bağlantıdan alır.
